# 전국 공공시설 개방 현황 대시보드

전국공공시설개방정보표준데이터 7,255건을 지역·시설 분류·이용 조건별로 탐색할 수 있는 정적 HTML 대시보드입니다.

## 주요 기능

- 전국·시군구와 7개 상위 시설 분류, 요금, 주말 운영, 신청 채널, 수용인원 필터
- OpenStreetMap 기반 위치 탐색, 지도 중심 주변 시설, 내 위치 거리순 정렬
- 시설 상세 정보, 주소 복사, 관리기관 연락, 네이버 지도·카카오맵 연결
- 최대 4개 시설 비교, 현재 조건 링크 공유, 검색 결과 CSV 내려받기·인쇄
- 데이터 최신성·정보 완성도 표시와 원자료/추정 분류 구분
- 모바일 카드와 데스크톱 표를 포함한 반응형·키보드 접근성 화면

## 데이터 갱신

원본 CSV는 CP949 인코딩을 사용합니다. 아래 명령으로 브라우저용 JSON을 다시 생성할 수 있습니다.

```bash
python scripts/prepare_data.py path/to/전국공공시설개방정보표준데이터.csv public/data/manifest.json
npm test
```

## 로컬 실행

```bash
npm ci
npm run dev
```

`main` 브랜치에 푸시하면 GitHub Actions가 `dist` 폴더를 GitHub Pages에 배포합니다.
